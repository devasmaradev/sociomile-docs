# 📚 Sociomie Documentation Center

Official documentation portal for Sociomie, an enterprise-grade omni-channel customer engagement platform developed by Ivosight.

This project provides a modern, responsive, and interactive documentation experience designed to help users, administrators, developers, and enterprise teams learn and navigate Sociomie efficiently.

---

## ✨ Features

### 🎨 Modern Documentation UI
- Enterprise-grade design system
- Responsive layout for desktop, tablet, and mobile
- Dark mode support
- Reading progress indicator
- Smooth animations and transitions

### 🔍 Advanced Search Experience
- Global documentation search
- Search overlay modal
- Keyboard shortcuts support
- Quick access tags
- Real-time search results

### 📖 Documentation Management
- Structured article system
- Category-based navigation
- Previous/Next article navigation
- Estimated reading time
- Last updated information

- Desktop navigation bar

```css
  --brand-accent: #00C2FF;
}
```

```javascript
const ARTICLES = {
   ...
}
```

inside:

```text
script.js
```
